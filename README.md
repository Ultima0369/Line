## 这他妈是什么

市面上有几百个 AI 聊天客户端。它们都做同一件事：你把文本敲进去，AI 吐文本出来。

**Line 不一样。** 它不是"聊天界面"，它是**给你的 AI 装上一个神经系统**。

你用过那些所谓的"AI 助手"后应该已经感觉到了——它们没有"在场感"。它们不知道你房间里现在是多少度，不知道窗外是不是在下雨，不知道你刚刚是不是被一个电话打断了思路。它们活在一个纯净的无菌文本空间里，跟你不在同一个世界。

Line 改变了这件事。

**本地跑一个小模型，接上传感器，做注意力和压缩处理。云端用大模型做深度推理。中间是一条私有通道。**

你的 AI 不再是一个等待你输入的空壳——它和你活在同一个物理空间里。

## 你能用它做什么（而且只有它能做）

| 场景 | 别人能做到吗 |
|------|------------|
| **环境感知对话**：AI知道你房间的温度、湿度、光照、噪声，并基于这些调整回复 | ❌ 没有任何聊天客户端做到 |
| **注意力调度**：温度骤变时主动提醒，而不是等你自己发现 | ❌ 需要物理传感器+注意力算法 |
| **离线生存**：断网时本地小模型维持基础对话（需额外配置） | ✅ 部分可以，但无法同时接传感器 |
| **私有语义协议**：你和你AI之间的信息传输是经过压缩和编码的 | ❌ 这是你的私有通道 |
| **认知外骨骼**：不只是问答，是持续的环境-认知耦合系统 | ❌ 市场上没有同类产品 |

## 怎么用

```bash
# 1. 装依赖
pip install requests pyyaml pydantic

# 2. 设置 API Key（推荐环境变量方式，不写进文件）
# Windows:
set DEEPSEEK_API_KEY=sk-你的key
# macOS/Linux:
export DEEPSEEK_API_KEY=sk-你的key

# 3. 开跑！
python main.py
```

看到提示符后直接打字聊天。输入 `/sensors` 查看环境数据，输入 `/status` 看系统状态。

## 为什么会有这个项目

因为一个很简单的观察：**人类不是在真空中思考的。**

你读这篇文章的时候，你房间的温度、湿度、气压、光照、噪声——都在影响你的认知状态。你的 AI 如果不知道这些，它就是瞎的。

而且，现有的 AI 架构有一个致命的"阻塞"问题：从你的大脑到你说话，到 AI 收到文本，到 AI 回传文本，到你解码——每一步都是损失。Line 的本地-云端双脑设计，就是为了在不损失信息密度的前提下，让这个通道尽可能短、尽可能厚。

| 层 | 技术 |
|----|------|
| 本地推理 | 可选：HuggingFace Transformers / DeepSeek API（小模型） |

| 传感器 | 模拟（内置）/ 真实硬件（DHT22, BMP280, BH1750） |
| 通信 | 私有语义压缩协议 |
| 语言 | Python 3.10+ |
