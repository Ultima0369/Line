# 01 · 快速开始

> **5 分钟跑起来。**

---

## 第一步：安装

```bash
# 进入项目目录
cd E:\Line

# 安装核心依赖
pip install -r requirements.txt
```

只需要装 `requests`, `pyyaml`, `pydantic` 三个基础包，其他都是可选的。

---

## 第二步：设置 API Key

**推荐方式** — 设置环境变量（安全，不会误提交）：

```bash
# Windows PowerShell
$env:DEEPSEEK_API_KEY="sk-你的key"

# Windows CMD
set DEEPSEEK_API_KEY=sk-你的key
```

**备选方式** — 编辑 `config.yaml`：

```yaml
cloud:
  api_key: "sk-你的key"
```

---

## 第三步：跑起来

### 模式 A：完整双脑对话（推荐）

```bash
python main.py
```

你会看到：

```
    ╔══════════════════════════════════════╗
    ║     Line — 双脑异构体认知框架        ║
    ║     本地感官皮层 + 云端新皮层        ║
    ╚══════════════════════════════════════╝

  🤖 双脑就绪。输入你的消息开始对话。
  📝 输入 /help 查看命令  |  /exit 退出
```

然后直接打字跟它聊就行。

### 模式 B：仅测试传感器

```bash
python main.py --sensors
```

会看到模拟的温湿度、气压、光照等传感器数据在终端滚动。

### 模式 C：查看配置

```bash
python main.py --config
```

---

## 第四步：试试内置命令

在双脑模式下：

| 命令 | 作用 |
|------|------|
| `/sensors` | 查看当前传感器数据 |
| `/status` | 查看系统状态 |
| `/clear` | 清空对话历史 |
| `/help` | 帮助 |
| `/exit` | 退出 |
