# 05 · 云端通信

> **如何跟云端大脑说话。**

---

## 云端桥接器

`cloud/bridge.py` 负责与 DeepSeek API 通信。

它的工作很简单：
1. 接收来自边缘处理器的上行数据包
2. 调用 DeepSeek API
3. 返回推理结果

---

## API 调用流程

```python
from line.cloud.bridge import CloudBridge

bridge = CloudBridge()
await bridge.initialize()

response = await bridge.ask(
    user_input="今天外面冷不冷？",
    sensor_context="tmp:26.5|hum:58.2",
    attention_context="l:0.6|s:active",
)

print(response["content"])
print(response["reasoning"])  # 推理过程
print(f"耗时: {response['latency']}s")
```

### 参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| `user_input` | ✅ | 用户的输入文本 |
| `sensor_context` | 可选 | 传感器数据摘要（如 "tmp:26.5\|hum:58"） |
| `attention_context` | 可选 | 注意力状态（如 "l:0.6\|s:active"） |
| `temperature` | 可选 | 生成温度 (0-1)，默认 0.7 |
| `max_tokens` | 可选 | 最大输出长度，默认 4096 |

### 返回值

| 字段 | 说明 |
|------|------|
| `content` | 回复文本 |
| `reasoning` | 推理过程（如果模型支持） |
| `usage.prompt_tokens` | 输入消耗的 token 数 |
| `usage.completion_tokens` | 输出消耗的 token 数 |
| `latency` | 请求耗时（秒） |

---

## 配置

```yaml
cloud:
  api_key: ""               # DeepSeek API 密钥（必填）
  base_url: "https://api.deepseek.com"
  model: "deepseek-reasoner"  # 云端模型
  timeout: 60                 # 超时秒数
  max_retries: 3              # 重试次数
```

### 模型选择

| 模型 | 特点 | 适合场景 |
|------|------|---------|
| `deepseek-reasoner` | 深度推理，展示思考过程 | 复杂问题，分析，写作 |
| `deepseek-chat` | 快速响应，成本低 | 日常对话，简单任务 |

## 没有 API Key 也能用

如果不设置 API Key，Line 会以"本地模式"运行：

```
⚠️ API 密钥未配置。请在 config.yaml 中填写 cloud.api_key，
或设置环境变量 DEEPSEEK_API_KEY。
```

此时云端推理不可用，但本地部分（传感器、注意力调度、上下文管理）仍然可以正常使用。

---

## 最佳实践

1. **API Key 用环境变量** — 不要写在代码里，用 `$env:DEEPSEEK_API_KEY`
2. **传感器上下文自动注入** — 边缘处理器会自动把传感器数据放入上行数据包
3. **不要手动拼 prompt** — 系统提示词会自动生成，包含传感器和注意力状态
