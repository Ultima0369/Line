# 07 · 注意力调度

> **如何让你的 AI 知道什么重要。**

---

## 注意力是什么

在 Line 框架里，"注意力"不是比喻，是一个**可计算的数值**。

每一条进入系统的信息——无论是你说的话、传感器的一个读数、还是系统的一个事件——都会被打一个"注意力分数"。分数高的，获得更多处理资源；分数低的，被压缩或忽略。

这就是你之前说的**注意力的精微调度**在工程层面的实现。

---

## 三个维度

```
注意力分数 = 优先级 × 0.4 + 紧迫度 × 0.35 + 新奇度 × 0.25
```

### 1. 优先级（0-1）：这件事本身重不重要

| 信息类型 | 优先级 |
|---------|--------|
| 温度超过 35°C 或低于 0°C | 0.9 |
| 你的输入 | 0.8 |
| 传感器常规更新 | 0.4 |
| 系统心跳 | 0.1 |

### 2. 紧迫度（0-1）：这件事需要多快处理

紧迫度 = 变化率 × 3 + 0.1（上限 1.0）

如果温度在 10 秒内从 26°C 升到 32°C，紧迫度是 0.9。如果是平稳变化，紧迫度是 0.1。

### 3. 新奇度（0-1）：这件事有多出乎意料

如果是第一次出现的信息，新奇度是 0.8。
如果和过去 10 条信息差不多，新奇度只有 0.3。

---

## 注意力信号

每条信息被评估后，生成一个 `AttentionSignal`：

```python
@dataclass
class AttentionSignal:
    source: str       # 信息来源
    content: Any      # 内容
    priority: float   # 优先级 0-1
    urgency: float    # 紧迫度 0-1
    novelty: float    # 新奇度 0-1
```

关键方法：

```python
signal.should_interrupt(threshold=0.7)
# 返回 True → 这条信息值得打断当前对话
# 返回 False → 可以等当前对话结束后再处理
```

---

## 注意力如何影响对话

场景：你在跟 Line 聊天，突然室温从 26°C 升到 34°C。

1. **传感器读取到变化**
2. **注意力过滤器检测到变化率异常** → 紧迫度 0.85
3. **温度接近高温阈值** → 优先级 0.9
4. **综合分数 = 0.9×0.4 + 0.85×0.35 + 0.8×0.25 = 0.86**
5. **0.86 > 0.7 → 打断当前对话**
6. 云端收到带注意力标记的上行包，回复会包含温度提醒

---

## 配置注意力参数

注意力筛选器的参数在 `edge/attention.py` 中，可以直接修改阈值：

```python
# 想让它更敏感 → 降低阈值
signal.should_interrupt(threshold=0.5)

# 想让它更迟钝 → 提高阈值
signal.should_interrupt(threshold=0.9)
```

---

## 调用方式

```python
from line.edge.attention import AttentionFilter

filter = AttentionFilter()

# 评估一条信息
signal = filter.evaluate("temperature", 34.5, {"source": "sensor"})
print(signal.attention_score)  # 0.86
print(signal.should_interrupt())  # True

# 获取注意力摘要（发给云端）
summary = filter.get_context_summary()
print(summary)
# {"status": "active", "attention_level": 0.6, ...}
```
