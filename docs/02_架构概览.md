## 三个核心模块

### 1. 传感器层（sensor/）

连接物理世界的接口。

- 支持：温湿度、气压、光照、噪声、系统状态（CPU/内存）
- 特性：即插即用、异步轮询、模拟模式（无硬件也可开发）
- 输出：标准化的 `SensorReading` 数据结构

### 2. 边缘处理器（edge/）

本地大脑。负责：

- **注意力预筛选**：判断当前什么信息重要，什么可以忽略
- **语义压缩**：把原始数据压缩成特征向量
- **上下文管理**：维护对话历史，自动摘要
- **本地快速响应**：简单问题本地直接回答

### 3. 云端桥接器（cloud/）

远程大脑。负责：

- 调用 DeepSeek API
- 接收压缩后的上行数据包
- 进行深度推理
- 返回推理结果

---

## 数据流（一次完整的对话）

```
你说话 
  → 传感器采集环境数据 
  → 边缘处理器构建上行数据包（含你的话 + 传感器 + 注意力状态）
  → 语义压缩（特征向量 + 摘要）
  → 云端深度推理
  → 解压返回
  → 显示回复 + 记录到上下文
```

---

## 为什么这样设计

1. **减少延迟** — 传感器处理和注意力筛选在本地完成，不需要等云端
2. **节省配额** — 只传压缩后的语义，不传原始数据
3. **离线可用** — 本地小模型可以独立处理基础对话
4. **隐私保护** — 原始传感器数据不出本地
5. **对话主权** — 你控制本地框架，云端只是可插拔的推理引擎
