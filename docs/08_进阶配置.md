## 完整配置参考

这是一份带注释的完整 `config.yaml`：

```yaml
# ============================================
# Line 框架完整配置
# ============================================

# --- 云端连接 ---
cloud:
  api_key: ""              # DeepSeek API密钥
  base_url: "https://api.deepseek.com"
  model: "deepseek-reasoner"  # 云端模型
  timeout: 60
  max_retries: 3

# --- 本地边缘处理 ---
edge:
  enabled: true
  mode: "api"               # "api" | "local_model" | "rule"
  
  # API 模式下的"小模型"（实际还是调 API，只是用小一点的模型）
  mini_model:
    model: "deepseek-chat"
    max_tokens: 512
  
  # 本地模型模式（需要安装 transformers + torch）
  local_model:
    name: "Qwen/Qwen2.5-1.5B-Instruct"
    device: "cpu"
    quantize: true
  
  # 上下文管理
  context:
    max_turns: 20
    summary_threshold: 10
    enable_compression: true

# --- 传感器 ---
sensor:
  enabled: false
  scan_on_start: true
  mock: true               # 无硬件时用模拟数据
  
  drivers:
    dht:
      enabled: false
      pin: 4
      type: "DHT22"
    pressure:
      enabled: false
      bus: 1
      address: 0x76
    light:
      enabled: false
      bus: 1
      address: 0x23
    system:
      enabled: true
      interval: 10
    audio:
      enabled: false
      device: null
      sample_rate: 16000

# --- 日志 ---
logging:
  level: "INFO"            # DEBUG | INFO | WARNING | ERROR
  file: "line.log"
  console: true
```

## 场景配置示例

### 场景 1：全离线 — 不想碰云端

```yaml
cloud:
  api_key: ""  # 留空

edge:
  mode: "local_model"
  local_model:
    name: "Qwen/Qwen2.5-1.5B-Instruct"
    device: "cpu"
    quantize: true

sensor:
  mock: true
```

需要：16GB+ 内存，安装 transformers + torch。

### 场景 2：纯传感器采集 — 不聊天

```bash
python main.py --sensors
```

### 场景 3：极致省成本 — 用便宜模型

```yaml
cloud:
  model: "deepseek-chat"      # 比 reasoner 便宜很多
  max_tokens: 1024
```

### 场景 4：高敏感监控 — 及时告警

```yaml
edge:
  interrupt_threshold: 0.4    # 降低阈值，更多环境事件会被注入对话
```

## 环境变量

| 变量名 | 说明 |
|--------|------|
| `DEEPSEEK_API_KEY` | DeepSeek API 密钥 |
| `LINE_API_KEY` | 同上，备选名 |
| `LINE_CONFIG_PATH` | 配置文件路径（默认 ./config.yaml） |

## 自定义开发

### 添加新的传感器驱动

1. 在 `line/sensor/` 下新建文件
2. 继承 `Sensor` 基类
3. 实现 `sensor_type` 属性和 `read()` 方法
4. 在 `manager.py` 的 `scan()` 方法中注册

### 修改注意力算法

编辑 `line/edge/attention.py`：
- 调整 `_compute_priority` 中的阈值
- 修改 `attention_score` 的权重比例
- 添加新的判断维度

### 扩展语义协议

编辑 `line/edge/compressor.py`：
- 在 `TYPE_SHORTHAND` 中添加新的传感器类型缩写
- 在 `build_upstream_payload` 中添加新的字段
