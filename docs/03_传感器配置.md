# 03 · 传感器配置

> **让 Line 能"感觉到"你周围的环境。**

---

## 两种模式

| 模式 | 说明 | 适合场景 |
|------|------|---------|
| **Mock（模拟）** | 软件生成虚拟数据，带日周期波动 | 开发测试、无硬件时 |
| **Real（真实）** | 连接物理传感器硬件 | 正式使用、研究 |

默认是 Mock 模式，开箱即用。

---

## 模拟传感器

无需任何硬件，`config.yaml` 中默认启用了 mock：

```yaml
sensor:
  mock: true
```

模拟数据包含：
- 🌡️ 温度（26±3°C，120秒周期波动）
- 💧 湿度（60±10%，180秒周期）
- 🌬️ 气压（1013±5hPa，300秒周期）
- ☀️ 光照（500±200lux，90秒周期）
- 🔊 噪声（40±10dB，45秒周期）

这些数据看起来像真的环境数据，适合开发阶段使用。

---

## 真实传感器（树莓派）

如果你有树莓派和传感器硬件：

```yaml
sensor:
  enabled: true
  mock: false    # 关闭模拟模式
  drivers:
    dht:
      enabled: true
      pin: 4
      type: "DHT22"     # 或 DHT11
    pressure:
      enabled: true
      bus: 1
      address: 0x76
    light:
      enabled: true
      bus: 1
      address: 0x23
```

硬件清单：

| 传感器 | 芯片 | 接口 | 价格 |
|--------|------|------|------|
| 温湿度 | DHT11/DHT22 | GPIO | ¥10-30 |
| 气压 | BMP280/BME280 | I2C | ¥15-25 |
| 光照 | BH1750 | I2C | ¥10-20 |

## Windows 下的传感器

在 Windows 上直接接硬件传感器比较麻烦，但有几种替代方案：

### 方案 A：用系统传感器
```yaml
sensor:
  drivers:
    system:
      enabled: true
```
这会读取 CPU 温度、内存使用率、负载等数据，不需要额外硬件。

### 方案 B：用串口（Arduino + 传感器）
通过 USB 串口连接 Arduino，Arduino 负责采集传感器数据。

```python
# 手动读取串口传感器示例
import serial
ser = serial.Serial('COM3', 9600)
line = ser.readline()  # 读取一行数据
ser.close()
```

### 方案 C：Mock 模式（开发期间最方便）
直接使用模拟数据开发，等硬件到位后再切换。

## 读取传感器数据

在双脑对话模式下，随时输入：

```
/sensors
```

会显示当前的传感器数据：

```
📡 🌡️ temperature: 26.3°C  |  💧 humidity: 58.7%  |  🌬️ pressure: 1013.2hPa
```

## 扩展：写你自己的传感器驱动

所有传感器继承 `line/sensor/base.py` 中的 `Sensor` 基类：

```python
from line.sensor.base import Sensor, SensorReading

class MyCustomSensor(Sensor):
    
    @property
    def sensor_type(self):
        return "my_sensor"
    
    async def read(self):
        # 从硬件读取数据
        value = await self._read_hardware()
        
        return SensorReading(
            sensor_id=self.sensor_id,
            sensor_type=self.sensor_type,
            value=value,
            unit="unit",
        )
    
    async def _read_hardware(self):
        # 你的硬件读取逻辑
        return 42.0
```

然后在 `main.py` 中注册：

```python
sensor_manager.register(MyCustomSensor("custom_01"))
```
