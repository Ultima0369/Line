# Line 双脑认知框架 · 文档

## 这是什么

**Line** 是一个本地-云端双脑协作层。

- **本地**（感官皮层）：小模型 + 传感器 + 注意力调度
- **云端**（新皮层）：大模型深度推理 + 知识注入
- **中间**：一条私有的语义压缩通道

它不是"另一个聊天客户端"。它是你和 AI 之间**重新分配对话主权**的框架。

## 设计原则

1. **本地能做的，不上云端** — 传感器滤波、注意力预筛选、简单响应，全在本地完成
2. **上云端的，必须是压缩过的** — 特征向量 + 语义摘要，不传原始数据
3. **云端只负责本地做不到的事** — 跨尺度推理、知识注入、复杂模式识别
4. **你拥有对话主权** — 本地框架完全在你控制下，云端只是一个推理引擎
