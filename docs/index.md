# Line · 文档

## 这是什么

**Line** 是一个带环境上下文的对话客户端：传感器轮询 → 注意力筛选 →
把环境状态打包进云端请求 → DeepSeek 回复。

- **本地**（边缘处理）：传感器 + 注意力调度 + 上下文打包
- **云端**（DeepSeek）：深度推理，消费本地打包的环境上下文
- **中间**：上行数据包（紧凑编码的环境 + 对话状态）

本地小模型推理是路线图项，当前推理都走云端。

## 设计原则

1. **环境感知** — 云端每次都拿到当前物理环境，回复能参考你所在的空间
2. **省 token** — 传感器状态以紧凑串进 system prompt，而非完整 JSON
3. **注意力调度** — 传感器读数越过物理阈值时，向对话流注入环境事件
4. **你拥有对话主权** — 本地框架完全在你控制下，云端是可插拔的推理引擎
