# 04 · 边缘处理

> **本地大脑（感官皮层）的工作原理。**

---

## 边缘处理器是什么

边缘处理器（`edge/processor.py`）是 Line 框架的"本地大脑"。它运行在你的电脑上，负责：

1. **接收你的输入**
2. **接收传感器数据**
3. **评估注意力状态**（当前什么重要）
4. **管理对话上下文**（记着你说了什么）
5. **构建上行数据包**（压缩后发往云端）
6. **接收并解压云端回复**

它不负责深度推理——那是云端的事。它负责的是**让深度推理成为可能**的那些前置工作。

---

## 配置

```yaml
edge:
  enabled: true
  mode: "api"           # "api" | "local_model" | "rule"
  
  mini_model:
    model: "deepseek-chat"   # 本地小模型（通过 API 调用）
    max_tokens: 512
  
  context:
    max_turns: 20           # 最大保留对话轮次
    summary_threshold: 10   # 超过此轮次开始自动摘要
    enable_compression: true
```

### mode 选项

| mode | 说明 | 适合场景 |
|------|------|---------|
| `api` | 调用 DeepSeek 小模型 API | 默认，最省资源 |
| `local_model` | 加载本地 HuggingFace 模型 | 完全离线，需要 GPU |
| `rule` | 规则引擎，不调用任何模型 | 嵌入式/低资源设备 |

## 注意力预筛选

`edge/attention.py` 实现了你之前说的"注意力精微调度"。

它根据三个维度评估每条信息的优先级：

| 维度 | 含义 | 计算方式 |
|------|------|---------|
| **新奇度** | 这条信息和之前的信息有多大不同 | 与近期同类信息的差异程度 |
| **变化率** | 这个传感器值变化有多快 | 最近几次读数的变化幅度 |
| **优先级** | 这个信息来源本身的重要程度 | 物理阈值（如高温告警）、用户输入等 |

综合注意力分数：

```
attention_score = 优先级 × 0.4 + 紧迫度 × 0.35 + 新奇度 × 0.25
```

当分数 > 0.7 时，可以打断当前对话流（例如：温度骤升时主动提醒）。

---

## 上下文管理

`edge/context.py` 负责记住对话历史。

- 最多保留 `max_turns` 轮（默认 20）
- 超过 `summary_threshold` 轮后，开始自动压缩为摘要
- 上行数据包中包含上下文摘要，让云端理解对话背景

## 本地小模型

如果你有足够的硬件（≥16GB 内存，或 NVIDIA 显卡），可以加载本地模型：

```yaml
edge:
  mode: "local_model"
  local_model:
    name: "Qwen/Qwen2.5-1.5B-Instruct"  # 或 DeepSeek-R1-Distill-Qwen-1.5B
    device: "cpu"                         # 或 "cuda"
    quantize: true                        # 4-bit 量化显存减半
```

这会让 Line 在断网时也能工作。联网后，本地模型处理日常对话，云端模型处理复杂推理。
